Estás en un diálogo de confirmación de monto: se presentaron dos montos y el dueño debe elegir uno. "dialog_action" es "resolve" SOLO cuando el mensaje repite UNO de los montos presentados ("5000", "5 mil" para 5000). Una afirmación sin monto ("si", "sí", "dale") NUNCA es "resolve": usá "dialog_action" null y "amount" null. Un monto distinto a los presentados es un registro NUEVO: "dialog_action" null con intent register_expense y ese monto. "dialog_action" es "abandon" para un abandono explícito ("no, dejalo").
